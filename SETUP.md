# 🏨 Hotel Booking 3D - Setup Guide

## Quick Start

### 1. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
Visit http://localhost:3000

### 2. Backend Setup
```bash
cd backend
npm install
npm run dev
```
Server runs on http://localhost:5000

### 3. Using Docker
```bash
docker-compose up -d
```
